# Life Dashboard

A personal productivity dashboard with Apple-inspired design featuring time management, task tracking, and quick links.

## Features

- **Live Clock & Greeting** - Real-time clock with personalized time-based greetings
- **Focus Timer** - Customizable Pomodoro timer (1-120 minutes) with presets
- **Task Management** - Add, edit, complete, and delete tasks with inline editing
- **Progress Tracking** - Visual progress bar showing task completion percentage
- **Quick Links** - Save and quickly access your favorite websites
- **Multi-Language** - Switch between Indonesian, English, Japanese, and German
- **Light & Dark Mode** - Automatic theme with manual toggle

## How to Run

1. Download or clone this repository
2. Open `index.html` in any modern browser
3. No installation, build process, or server required!

Works completely offline with all data stored locally in your browser.

## Supported Browsers

- Google Chrome
- Mozilla Firefox
- Microsoft Edge  
- Apple Safari

## GitHub Pages

To deploy on GitHub Pages:
1. Push to your GitHub repository
2. Go to Settings → Pages
3. Select your branch and root folder
4. Access at: `https://[your-username].github.io/[repo-name]/`

## Privacy

All data stays on your device. No tracking, no analytics, no external requests.
